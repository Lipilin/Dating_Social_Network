# 🚀 Boltaem — Платформа для совместных путешествий

**Коротко:** Веб-приложение для поиска попутчиков и публикации маршрутов с встроенным мессенджером. Монорепозиторий с фронтендом, бэкендом и полной поддержкой Docker.

---

## 📦 Технологии

### 🎨 Frontend
- **React 18** + **TypeScript** — интерфейсы
- **Vite** — сборка и разработка
- **React Router** — маршрутизация
- **Axios** — HTTP-запросы с перехватчиками JWT
- **ESLint** — качество кода

### ⚙️ Backend
- **Node.js 20 LTS** + **Express 5** — сервер
- **TypeScript** — типизация
- **Prisma 6** — ORM
- **AdminJS** — административная панель
- **JWT** (access + refresh) — аутентификация
- **bcryptjs** — хеширование паролей
- **cookie-parser** — работа с httpOnly cookie
- **helmet** — безопасность

---
