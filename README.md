# 💑 Pick Me Up — платформа знакомств для путешествий

**Коротко:** Веб-приложение для знакомств с единомышленниками и поиска попутчиков. Пользователи создают профили с интересами, публикуют объявления о поездках и делятся историями в блоге. Монорепозиторий с фронтендом, бэкендом и полной поддержкой Docker.

---

## 📦 Технологии

### Архитектура
- **npm workspaces** — монорепозиторий (`backend`, `frontend`, `common`)
- **@pick-me-up/common** — общий пакет с TypeScript-типами, Zod-схемами валидации и email-шаблонами для обоих сервисов

### 🎨 Frontend
- **React 19** + **TypeScript** — интерфейсы
- **Vite 8** — сборка и dev-сервер с HMR
- **React Router 7/8** — маршрутизация
- **Tailwind CSS 4** + **SCSS** — стилизация
- **Axios** — HTTP-запросы с `withCredentials` для cookie-based auth
- **Zod** — клиентская валидация форм
- **Swiper** — карусель объявлений на главной
- **ESLint** — качество кода

### ⚙️ Backend
- **Node.js 20** + **Express 5** + **TypeScript**
- **Prisma 5** — ORM и миграции
- **tsx** — запуск в dev-режиме, **tsc** — production-сборка
- **jose** — JWT (access, refresh, email-подтверждение, сброс пароля)
- **bcryptjs** — хеширование паролей
- **cookie-parser** — работа с httpOnly cookie
- **helmet** — security headers и CSP
- **express-session** — сессии AdminJS
- **nodemailer** — отправка email через SMTP
- **multer** — загрузка изображений (аватар, баннер, посты, объявления)
- **qs** — парсинг вложенных query-параметров фильтров
- **@faker-js/faker** — генерация dev-данных для seed

### 🗄️ База данных
- **MySQL 8** — основное хранилище (Prisma provider: `mysql`)
- Миграции и seed-скрипты (`seedProd.ts`, `seedDev.ts`)

### 🔐 Аутентификация
- **JWT access token** (5 мин) + **refresh token** (1 день / 30 дней с «Запомнить меня»)
- Токены в **httpOnly cookies**, refresh-токены хранятся в БД
- Автообновление сессии на фронте через `withRefreshing()` при 401
- Отдельные JWT-секреты для email-подтверждения и сброса пароля

### 🛠️ Админ-панель
- **AdminJS 7** + `@adminjs/prisma`, `@adminjs/express`, `@adminjs/upload`
- Русская локализация, CRUD всех сущностей, превью изображений, rich text

### 🐳 DevOps
- **Docker Compose** — backend (`:3000`), frontend (`:5173`), MySQL 8
- Multi-stage **Dockerfile** для backend (develop / build / production)
- Vite proxy: `/api` и `/resources` → backend

## 💡 Реализованные идеи

### Профили и регистрация
- **Многошаговая регистрация** (3 шага): учётные данные → выбор интересов → личные данные (имя, возраст ≥18, город, пол, описание)
- **Профиль** с аватаром, баннером, интересами, объявлениями и постами
- **Предпочтение пола** попутчика (MALE / FEMALE / ANYBODY) — при создании объявления о поездке
- **lastSeen** — отметка последней активности пользователя

### Жизненный цикл пользователя и модерация
- Статусы: `NEW` → (email confirm) → `PENDING_APPROVEMENT` → (админ) → `REGISTERED` / `BANNED`
- Весь пользовательский контент (объявления, посты) проходит модерацию: `PENDING_APPROVEMENT` → `PUBLISHED`
- Публичный API отдаёт только одобренный контент от зарегистрированных пользователей
- **Проверка владельца** (`assertContentOwnership`) при редактировании и удалении

### Аутентификация и безопасность
- Login / logout / me с авто-refresh access token
- **«Запомнить меня»** — увеличенный срок refresh-cookie (30 дней)
- Email-подтверждение
- Сброс пароля по email с одноразовым токеном (TTL 1 час)

### Объявления и поиск
- CRUD объявлений о поездках: маршрут, даты, описание, иконка, привязанные интересы
- **Фильтрация на главной**: пол, цель (интерес), пункт отправления и назначения
- Карусель Swiper с объявлениями, пагинация на `/announcements`

### Блог и CMS
- CRUD постов с заголовком, контентом, изображением и **тегами** (JSON)
- **CMS статических страниц** — `/about`, `/privacy`, `/terms`, `/help` загружаются из БД через catch-all роут
- Email-шаблоны хранятся в БД и редактируются через AdminJS (плейсхолдеры `{{confirmLink}}`, `{{resetLink}}`)

### Общий пакет `common`
- Единые Zod-схемы валидации для frontend и backend — одна точка правды для правил форм
- Общие TypeScript-типы API-ответов и сущностей

### Dev-инфраструктура
- Prod-seed: категории, интересы, email-шаблоны, статические страницы
- Dev-seed через Faker: сотни пользователей, объявлений и постов для локальной разработки

## 🐳 Docker

Проект полностью контейнеризирован. Запуск всех сервисов (frontend, backend, MySQL) одной командой:

```bash
docker-compose up -d --build
```

### ESLint

Чистота кода отслеживается с помощью ESLint:

```bash
npm run lint
```
